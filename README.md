# PediAtlas

An interactive pediatric education platform designed to teach disease processes through anatomy, pathophysiology, clinical reasoning, and evidence-based medicine.

---

## Current Modules

- Bronchiolitis
- Asthma
- Pneumonia
- Pertussis

---

## Features

- Anatomy localization
- Pathophysiology animations
- Diagnostic workups
- Management algorithms
- Clinical pearls
- Interactive quizzes
- Evidence-based references

---

## Technology

- Next.js
- TypeScript
- Tailwind CSS
- Vercel
